# React + JS Таблица пользователей

## Установка и запуск

### Требования

- Node.js v22 или выше
- npm v10 или выше
- Git (для клонирования)

### 1. Проверка версий

Перед началом убедитесь, что у вас установлены правильные версии:

`bash`

node -v

# Должно быть v22.x или выше

npm -v

# Должно быть v10.x или выше

# Запуск проекта

## 1. Клонировать репозиторий

git clone

## 2. Перейти в папку проекта

cd usersTable

## 3. Установить зависимости

npm install

## 4. Запустить development сервер

npm run dev

## 5. Открыть в браузере

http://localhost:5173

## Описание

Приложение для отображения и управления таблицей пользователей с возможностями:

- Сортировки по всем полям (возрастание/убывание)
- Фильтрации данных
- Постраничного отображения
- Просмотра детальной информации в модальном окне
- Ресайза колонок таблицы

## Технологии

- React 18+
- Vite
- SCSS Modules
- Fetch API

### Основные возможности

- Загрузка данных с [DummyJSON](https://dummyjson.com/docs/users)
- Сортировка по всем колонкам
- Фильтрация по текстовым и числовым полям
- Ресайз колонок (мин. ширина 50px)

### Дополнительные фичи

- Модальное окно с деталями пользователя
- Пагинация с интеллектуальным отображением страниц
- Оптимизированная производительность
- Обработка ошибок загрузки
